🔧 INSTRUCCIONES: HACER PÚBLICO EL BUCKET S3
================================================================================

PROBLEMA ACTUAL:
----------------
- El bucket 's3-proyectos' es PRIVADO
- Las imágenes retornan HTTP 403 - Access Denied
- Las URLs firmadas no funcionan (posible problema de permisos IAM)

SOLUCIÓN: Hacer público el bucket solo para imágenes de productos
------------------------------------------------------------------

PASO 1: Desactivar Block Public Access (en AWS S3 Console)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
1. Ve a: https://s3.console.aws.amazon.com/s3/buckets/si2-proyectos
2. Click en pestaña "Permissions"
3. En "Block public access (bucket settings)", click "Edit"
4. DESMARCAR: "Block all public access"
5. Click "Save changes"
6. Confirmar escribiendo "confirm"

PASO 2: Añadir Bucket Policy
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
1. En la misma pestaña "Permissions"
2. Scroll down a "Bucket policy"
3. Click "Edit"
4. Pegar esta política (está en el archivo s3-bucket-policy.json):

{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Sid": "PublicReadGetObject",
      "Effect": "Allow",
      "Principal": "*",
      "Action": "s3:GetObject",
      "Resource": "arn:aws:s3:::si2-proyectos/si2-ecommerce-images/*"
    }
  ]
}

5. Click "Save changes"

PASO 3: (Opcional) Configurar CORS si el frontend está en otro dominio
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
1. En pestaña "Permissions"
2. Scroll down a "Cross-origin resource sharing (CORS)"
3. Click "Edit"
4. Pegar:

[
  {
    "AllowedHeaders": ["*"],
    "AllowedMethods": ["GET", "HEAD"],
    "AllowedOrigins": ["*"],
    "ExposeHeaders": []
  }
]

5. Click "Save changes"

PASO 4: Verificar que funciona
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Ejecuta en tu terminal:

    python test_catalog_images.py

Deberías ver:
    ✅ IMAGEN ACCESIBLE
    Status: HTTP 200

================================================================================
📝 NOTAS IMPORTANTES
================================================================================

1. Esta política SOLO hace pública la carpeta 'si2-ecommerce-images/'
   El resto del bucket sigue siendo privado.

2. Las imágenes de productos son contenido público de un e-commerce,
   por lo que es seguro hacerlas públicas.

3. Si NO puedes modificar el bucket (no tienes permisos), contacta
   al propietario del bucket AWS.

4. Una vez que el bucket sea público, el código ya está actualizado
   para usar URLs directas (más rápido y sin expiración).
